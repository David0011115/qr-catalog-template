# Капли 3D — где что лежит (с версии 2.3.0, модули)

Игра больше не один огромный `index.html`. Поведение прежнее: код игры при запуске
склеивается в одну функцию, как раньше. Но **править нужно отдельные файлы**.

| Файл | Что внутри |
|---|---|
| `index.html` | только разметка экранов (карточки, окна, кнопки) |
| `css/01-base.css` | основные стили: меню, раунд, магазин, профиль, окна |
| `css/02-leagues.css` | Лига и Хаос-лига |
| `css/03-chat.css`, `css/05-chat-2.css` | чат, темы чата, смайлики, строка ввода |
| `css/04-features.css` | праздничные коробки, пауза и цели, сундуки ×5, окно предмета |
| `js/game/01-config.js` | **настройки и контент**: `TEST_MODE`, константы, способности, скины, эффекты, питомцы, Хаос-лига |
| `js/game/02-save.js` | сохранение, миграции, лиги-сезоны |
| `js/game/03-scene.js` | 3D-сцена, внешний вид капель (материалы скинов), частицы |
| `js/game/04-arena.js` | шипы, события арены, клетки, масса, выброс |
| `js/game/05-achievements.js` | достижения |
| `js/game/06-abilities.js` | способности в раунде, боты-способности |
| `js/game/07-round.js` | бонусы, управление, мозг ботов, симуляция, HUD |
| `js/game/08-menus.js` | меню, обучение, новости, магазин, гардероб, коллекции, промокоды |
| `js/game/09-sound.js` | звук и музыка |
| `js/game/10-items-chests.js` | окно предмета, сундуки, праздничные коробки, настройки |
| `js/game/11-leagues.js` | значки сезонов, эмблемы, Лига, Хаос-лига |
| `js/game/12-profile.js` | профиль, витрина, фоны профиля, рамки |
| `js/game/13-world.js` | предпросмотр арены, цикл отрисовки, питомцы, логотипы |
| `js/game/14-net.js` | аккаунты, облачное сохранение, чат, личка, рейтинг, друзья |
| `js/game/15-boot.js` | запуск игры (последние строки) |
| `js/loader.js` | склеивает файлы из `js/game/` при запуске |
| `js/emotes.js` | смайлики-капли |
| `js/app.js` | версия игры (`APP_VER`, `APP_LABEL`), офлайн-режим, установка |
| `sw.js` | офлайн-кэш: номер `CACHE` поднимать при каждом обновлении |

## Правила
1. Файлы в `js/game/` — части **одной** функции: переменные и функции видны из любого файла.
   Порядок файлов важен, он задан в `js/loader.js`.
2. Новый файл кода: добавить его имя в список `FILES` в `js/loader.js` **и** в список `CORE` в `sw.js`.
   Новый файл стилей: подключить `<link>` в `index.html` и добавить в `CORE`.
3. Пути к картинкам внутри `css/` пишутся от папки `css/`: `url("../chat-cosmos.svg")`.
4. Перед заливкой `TEST_MODE` в `js/game/01-config.js` должен быть `false`.
5. После любого обновления поднять `CACHE` в `sw.js`.

`tools/` — скрипты: разбиение (`split.py`), чистка мёртвых стилей (`css-clean.js`),
тестовая сборка, проверка экранов и сравнение стилей до/после (`style-diff.js`).

Перед тем как добавлять режимы, прочитай «Принципы контента» в `ROADMAP.md`: постоянных режимов около 10, новый — только на замену старому.
