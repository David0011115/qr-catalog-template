# Разбиение игры на модули

`split.py` раскладывает `kapli-3d/index.html` по файлам, не меняя поведение игры:

- `css/01-base.css … 05-*.css` — все стили в исходном порядке (каскад тот же);
- `js/game/01-config.js … 15-boot.js` — код игры по темам; `js/loader.js` при запуске
  склеивает их обратно в одну функцию, байт в байт как прежний единый `<script>`;
- `js/emotes.js`, `js/app.js` — смайлики и офлайн-режим;
- `sw.js` — в список офлайн-кэша добавлены новые файлы.

Скрипт воспроизводимый: в день перехода его запускают на самом свежем main,
поэтому правки, сделанные в main за это время, не теряются и не конфликтуют.

```bash
python3 kapli-3d/tools/split.py kapli-3d /tmp/kapli-split      # разложить
python3 kapli-3d/tools/build-test.py /tmp/kapli-split /tmp/kapli-test   # тестовая сборка
```

После проверки содержимое `/tmp/kapli-split` заменяет папку `kapli-3d` (и `tools/` остаётся).
